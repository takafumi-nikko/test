# スーパーニッコー・サプライチェーン連携システム

スーパーニッコー、卸業者「野菜王」、福祉施設「ほっこり」、およびシステム運営会社（JE）が利用するサプライチェーン連携のためのMVPです。

## プロジェクト構成

- `server/`: Node.js (Express) ベースのシンプルなAPIサーバー。デモ用にメモリ内データストアを使用しています。
- `client/`: React + Vite + MUI によるフロントエンド。JE 管理画面、スーパー店舗向け商品管理、卸業者向け注文確認、福祉施設向け購入画面を含みます。

## セットアップ

```bash
# 依存関係のインストール
cd server && npm install
cd ../client && npm install

# サーバー起動
cd ../server && npm run start

# フロントエンド起動（別ターミナル）
cd ../client && npm run dev
```

- API サーバーは既定で `http://localhost:4000` で待受けます。
- Vite 開発サーバーは `http://localhost:5173` で起動し、`/api` へのリクエストをバックエンドにプロキシします。

## 主な機能

### JE 管理ダッシュボード
- KPI カード、未対応アラート、直近の取引ログの可視化
- ユーザー管理（フィルター、CRUD、アクティブ/停止切替）
- 商品マスタ管理（フィルター、登録・編集・削除）
- 取引ログ検索（条件指定、CSV エクスポート）

### スーパー店舗
- 商品一覧の検索・フィルタリング
- 商品の登録・編集・削除

### 野菜王（卸業者）
- 注文一覧（ステータス別フィルタ）
- 出荷待ち/完了へのステータス更新

### 福祉施設（ほっこり）
- 商品カード閲覧・注文
- 注文キャンセル、履歴確認

> **注意:** 本MVPでは永続化を行っておらず、アプリ再起動時にデータは初期化されます。
